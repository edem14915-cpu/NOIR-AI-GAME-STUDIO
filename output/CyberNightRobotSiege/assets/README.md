# Cyber Night: Robot Siege
3D Cyberpunk FPS Mobile Game built in Godot 4.4.

### Game Features:
- 3D Night city environment with volumetric fog and neon lighting
- Player FPS controller with assault rifle recoil and muzzle flash
- Robot AI enemies with hit effects
- 3 progressive waves of difficulty
- Complete HUD (HP, Ammo, Wave counter)
- Mobile Virtual Joystick + Drag Touch Look + Fire & Reload buttons
- Game Loop: Start Menu -> Gameplay -> Game Over / Victory Screen
